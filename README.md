# KMU Microsoft-Berater

Vertriebstool für Microsoft 365 in kleinen Betrieben bis 15 Mitarbeitende. Gemacht für Verkäuferinnen und Verkäufer ohne Microsoft-Vorwissen.

**Bereiche**
- **Beraten:** 8 Fragen in Kundensprache, daraus Paketempfehlung (Business Basic, Standard oder Premium) mit Begründung, Alternativen und Monatspreis
- **Vergleichen:** die drei Business-Pakete in Alltagsbeispielen, Microsoft-Produktnamen zuschaltbar, Detailtabelle aus dem M365-Explorer
- **Spickzettel:** Einwände mit Antworten, Fakten und Glossar

Außerdem: Kundenansicht ohne Verkäufer-Hinweise, Zusammenfassung als PDF, Preise anpassbar.

Alles steckt in einer Datei (`index.html`) und läuft ohne Server über GitHub Pages.

Preise: Microsoft-Listenpreise netto, Stand Oktober 2026. Orientierungshilfe ohne Gewähr, kein Ersatz für die verbindlichen Microsoft-Lizenzbedingungen.
